07

FigmaToRoblox

Node.js · Luau

Diseñás una pantalla en Figma, copiás un código de seis letras y la pegás en Roblox Studio. FigmaToRoblox la reconstruye como UI nativa de Roblox y le conecta los efectos.

  • Plugin de Figma que convierte cada capa en datos: posición, tamaño, rellenos, bordes, esquinas y texto.
  • Efectos con solo nombrar la capa (crecer, aplastar, aparecer) y vista previa antes de exportar.
  • Servidor local en Node sin dependencias que guarda el diseño seis horas y sube las imágenes a Roblox.
  • JavaScript
  • Node.js
  • Luau
  • Figma API

06

Reservini

Python · Flask

Reservas online para negocios chicos como barberías, profes particulares o consultorios. El dueño carga servicios y horarios, comparte el link y los clientes eligen un turno libre.

  • Página pública con los turnos libres de las próximas dos semanas y filtros por día y franja horaria.
  • Nunca da el mismo turno dos veces, y manda mail de confirmación y recordatorio.
  • Panel con las próximas reservas, en inglés y español, cualquier zona horaria y doce monedas.
  • Flask
  • SQLAlchemy
  • PostgreSQL
  • GitHub Actions

E-commerce API

TypeScript · Prisma

El backend de una tienda online: cuentas con JWT, roles de cliente y admin, catálogo con stock, pedidos y estadísticas, con una página de prueba incluida.

  • Node.js, TypeScript y Express sobre PostgreSQL con Prisma, y validación con Zod.
  • Pedidos dentro de una sola transacción, para que dos compradores no se lleven la última unidad.
  • Cancelar un pedido devuelve el stock, y los admins ven usuarios y estadísticas.

04

mpeasy

Extensión · Python

Una extensión que descarga audio y video de YouTube, Facebook, Instagram y TikTok, pero no es un descargador más: se conecta a un programa en tu PC, así que los archivos no pasan por las descargas del navegador y llegan más rápido.

  • Se comunica por native messaging con Python, yt-dlp y ffmpeg corriendo en tu PC.
  • Elegís las carpetas de destino, la calidad y el formato: MP4, MP3 o pistas separadas.
  • Recortar: marcás inicio y fin sobre el video y baja solo esa parte.
  • JavaScript
  • Python
  • yt-dlp
  • ffmpeg
